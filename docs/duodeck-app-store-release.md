# DuoDeck 1.0 — Sill fork release notes

This branch contains the original DuoDeck prototype for the Sill fork. The [standalone DuoDeck repository](https://github.com/samihalawa/2026-CODEX-DuoDeck) is the current product source. Its [release checklist](https://github.com/samihalawa/2026-CODEX-DuoDeck/blob/main/docs/release-checklist.md) supersedes the earlier App Store handoff for this branch.

The prototype introduced an adjustable trackpad and four shortcut presets for a half-folded iPhone Duo. It builds on [Sill](https://github.com/Saffsanity/sill) under the Apache 2.0 license. See [setup and controls](../DUODECK.md) to try this branch.
